## 背景

我想搞清楚一件事：前端点一下按钮，数据到底是怎么被存进去、又怎么被取出来的。
只看教程不够，得自己写一个完整的后端服务才算数。

## 打算做什么（还没开工）

做一个最小的「待办清单」API：增、删、改、查四个接口，数据落在 SQLite 里，
再用 FastAPI 自带的交互式文档把接口说明白，方便自己测。

技术选型是 **Python + FastAPI + SQLite**（和这个仓库后端的 ADR-004 保持一致）。
现在还在补 HTTP 基础，等基础打牢再动手。
