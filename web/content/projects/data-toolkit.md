## 背景

日常处理 CSV 数据时，经常需要反复执行洗掉空值、统一格式、算统计量、画图等步骤，每次都手敲一遍既慢又容易漏。
正好借这个痛点，一来为了**系统学习 pandas** 并将其应用于实战，二来为了**构建一个能拿得出手的真实作品**来充实个人作品集，于是决定动手封装这个小工具。

## 做了什么

读取 CSV 数据后，按部就班地进行数据清洗、统计分析与可视化输出。工具封装了简单的命令行参数（`--by/--value/--report/--encoding`），方便灵活指定分组字段、数值列、报告形式和文件编码。支持统计形状、缺失值、dtype、均值中位数及分组计数，并可直接出图。

## 技术栈

Python 3.11 / pandas / matplotlib / argparse / venv + 锁大版本。使用原生 argparse 实现命令行交互，matplotlib 负责最终图表的渲染。

## 难点与收获（重点）

1. **中文图表字体**：初次出图时中文显示为方块，查阅文档后通过修改 `matplotlib.rcParams` 的 `font.sans-serif` 解决了字体问题。
2. **`(s != 0).sum()` 会把 NaN 算进去**：在 pandas 里 `NaN != 0` 返回 True，所以空缺值会被算成
   「非零」；正确做法是用 `(s == 0).sum()` / `(s < 0).sum()`（NaN 参与比较恒为 False），
   不要用 `!=`，也不要指望 `.sum(skipna=True)`。
3. **数值列启发式判断**：不能盲目把所有列都当数值列处理，经过摸索，设定“数值占比 ≥60%”作为启发式规则来判断该列是否为数值列。
4. **异常输入处理**：针对三种坏输入（如文件不存在、编码错误、表头缺失），不直接向用户抛出底层的堆栈报错，而是转换为人类能听懂的自然语言提示。
